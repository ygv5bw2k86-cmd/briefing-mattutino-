1. INTELLIGENZA ARTIFICIALE & TECNOLOGIA (Focus: Costruire)

Google ha introdotto in Vertex AI (la piattaforma cloud di Google per creare e usare intelligenze artificiali) un sistema di agent retrieval (un meccanismo che permette a un'intelligenza artificiale di cercare informazioni dentro archivi di file aziendali, come documenti e video, prima di rispondere). Questa funzione elimina la necessità di costruire sistemi complessi e personalizzati per il cosiddetto chunking (l'azione di tagliare un documento lungo in pezzetti più piccoli per farli leggere all'AI) e per gli embedding (la trasformazione di parole e frasi in stringhe di numeri che il computer sa interpretare e confrontare). Ora i developer possono caricare file direttamente su Cloud Storage (il servizio di archiviazione file nel cloud di Google) e interrogarli con una singola chiamata API (Application Programming Interface, ovvero un insieme di regole che permette a programmi diversi di comunicare tra loro), ottenendo risposte con numeri di pagina citati e risultati con timestamp (marche temporali precise) per i video. Per uno sviluppatore che vuole creare un assistente aziendale in grado di analizzare manuali tecnici o video di riunioni, questo significa poter saltare settimane di configurazione backend e concentrarsi solo sull'interfaccia utente. Sempre in ambito di sicurezza e affidabilità dei sistemi intelligenti, Google ha rilasciato le semantic governance policies (politiche di governance semantica, ossia regole di controllo basate sul significato del linguaggio naturale che verificano le azioni di un'intelligenza artificiale prima che vengano eseguite). Questo strumento serve a bloccare i tentativi di prompt injection (una tecnica in cui un utente malintenzionato inserisce comandi nascosti in un testo per costringere l'AI a fare ciò che non dovrebbe) e l'intent hijacking (il dirottamento dell'intenzione dell'utente). Sfruttando un motore di policy collegato a un Agent Gateway (una porta d'accesso centralizzata che gestisce e controlla tutte le chiamate fatte dagli agenti software), ogni comando proposto dall'agente viene valutato rispetto all'intento originale dell'utente. Se state programmando un agente AI che deve interagire con database aziendali o inviare email, potete allegare vincoli in linguaggio naturale (come "non condividere mai i dati dei clienti all'esterno") per impedire comportamenti anomali o usi impropri degli strumenti (tool misuse).
