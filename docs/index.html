Sempre nell'ecosistema Google, sono state introdotte le semantic governance policies (politiche di governance semantica, ossia regole di sicurezza basate sul significato del linguaggio naturale per impedire a un'intelligenza artificiale di compiere azioni dannose o non autorizzate) (Google Developers Blog). Questo sistema protegge gli agenti AI da attacchi come l'indirect prompt injection (una vulnerabilità in cui un utente malintenzionato nasconde istruzioni dannose in una pagina web o in un documento che l'AI legge, spingendola a eseguire comandi non voluti) e l'intent hijacking (il dirottamento dell'intenzione originale dell'utente).
